# Hermes Harness DSH 快速上手 / Hermes Harness DSH Starter Kit

本技能提供 Hermes Harness 与 DSH 衍生的上手路径：三步安装、preset/skill 使用方式与三个示例场景，配合 example/ 示例文件使用。

This skill provides the onboarding path for Hermes Harness and its DSH derivatives: three-step installation, preset/skill usage, and three example scenarios, backed by the files under example/.

## When to use / 何时使用

新用户需要了解 Hermes Harness、安装 DSH 衍生或学习 preset/skill 用法时。

Use when a new user needs to understand Hermes Harness, install DSH derivatives, or learn preset/skill usage.

## Workflow / 工作流

1. 阅读 README 的 Hermes Harness 是什么。
2. 按 Quick start 三步安装 preset/skill。
3. 对照三个示例场景演练。
4. 参考 example/preset.yml 与 example/SKILL.md 自建产物。
